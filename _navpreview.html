Bottom-nav icon styles

Five candidates. Same 5 tabs, same dark/pink aesthetic, only the icon language differs. The Lineup tab is shown as active in each so you can see the active vs inactive treatment.

1 · Outlined line (Feather / Lucide)

Thin 1.6px stroke, no fill. Light, breathable. The Spotify / Notion / GitHub Mobile look. Most modern and elegant.

2 · Filled (Material Filled)

Solid shapes, single color. Heavier, more "app-like". Google's Material default.

3 · Duotone (Phosphor)

Soft fill behind a line stroke. Subtle, layered, gentle. Nice for an aesthetic-led app.

4 · Line + accent dot under active

Same outline as #1, but the active state shows a small pink dot underneath instead of a tinted background. Very minimal, very modern (Apple-Music-like).

5 · Bold geometric (heavier stroke)

2.2px stroke, simplified glyphs. Reads bigger, almost like an icon poster. Confident; less delicate than #1.

Open _navpreview.html directly. Tap any tab in any row to swap the active state across that nav so you can compare every icon in active and inactive states. Once you decide, tell Claude which style number you want.
